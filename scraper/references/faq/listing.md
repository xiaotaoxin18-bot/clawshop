# 抖店 FAQ — 上架与商品规则

> 供 AI agent 在用户问上架规则、商品审核问题时按需加载
> 触发词：上架、审核、商品规范、图片、标题优化

## 商品审核

- 新商品/编辑商品提交后进入审核
- 通常审核时间：**1-24 小时**
- 审核驳回常见原因：
  - 标题含违禁词（如「代发」「最」「第一」）
  - 主图不合规（白底图不白、有水印、非3:4比例）
  - 类目错放
  - 属性不完整
  - 品牌侵权

## 标题规范

**公式**：核心词 + 属性词 + 场景词 + 长尾词

```
✅ 创意十二生肖黄铜钥匙扣男女情侣款汽车挂件生日礼物
❌ 钥匙扣
```

**禁止**：
- 「代发」「批发」「一件代发」等词（消费者端可见）
- 「最」「第一」「全网最低」等极限词
- 特殊符号乱用

## 图片规范

| 要求 | 标准 |
|------|------|
| 主图数量 | 至少 3 张，建议 5 张 |
| 主图尺寸 | 3:4 比例，至少 600×800px |
| 白底图 | 第 1 张必须是白底图（纯白背景） |
| 视频 | 建议上传 15-60 秒商品视频 |
| 图片大小 | 单张 ≤ 2MB |
| 格式 | JPG / PNG |

> **图片上传无法自动化**：抖店用的 React input[type=file] 被拦截，需手动操作。
> 或用 1688「铺货」功能（但铺货来自 Chrome 扩展的 Shadow DOM，同样无法自动化）。

## 商品质量分

| 分数 | 等级 | 行动 |
|------|------|------|
| 90+ | 优秀 | 保持 |
| 80-89 | 良好 | 可优化属性 |
| 70-79 | 及格 | 重点优化 |
| <70 | 待优化 | 考虑下架重发 |

## 批量上下架

- 支持最多 100 个商品同时操作
- 搜索框接受逗号分隔的商品ID
- 批量下架后商品仍在商家后台，可重新上架
- 批量上架：商品审核通过后，可将下架商品批量上架
